## Modularized codebase for LLM-friendly navigation and context sizing

Split every oversized source file into small, single-responsibility modules with `//!` headers and directory `README.md` indexes so an agent can locate and read only the relevant slice.

- **WHAT:**
  - `crates/cometdesk/src/layout/data.rs` (10,116 lines) -> `crates/cometdesk/src/layout/data/*.rs` (one `@generated` file per locale via `scripts/gen-layouts.py`, max 468 lines).
  - `apps/cometdesk-gui/src/console.rs` (4,383 lines) -> `apps/cometdesk-gui/src/console/` (30 files across `menus/`, `ui/`, `palette/`, max 332 lines).
  - `crates/cometdesk-clip/src/lib.rs` (1,705 lines) -> `limits.rs`, `error.rs`, `protocol.rs`, `wire.rs`, `endpoint/{mod,handshake,send_loop,recv_loop}.rs`, `tests/{mod,control}.rs` (max 293 lines).
  - `apps/cometdesk-gui/src/devices.rs` (1,315 lines) -> `apps/cometdesk-gui/src/devices/{mod,model,reachability,list,form_modal,remove_dialog,prompt}.rs` (max 384 lines).
  - `apps/cometdesk-gui/src/clipsync.rs` (1,312 lines) -> `apps/cometdesk-gui/src/clipsync/{mod,bridge,state,settings,types,supervise,run,files,notes,dirlist,insert,capture,update,tests}.rs` (max 310 lines).
  - `apps/cometdesk-gui/src/theme.rs` (1,167 lines) -> `apps/cometdesk-gui/src/theme/{mod,colors,text,logo,frames,buttons,dropdown,controls,icons}.rs` (max 245 lines).
  - `apps/cometdesk-agent/src/info.rs` (864 lines) & `main.rs` (516 lines) -> `info/{mod,linux,macos,windows}.rs` and `session.rs` (max 297 lines).
  - `crates/cometdesk-cli/src/{main,commands}.rs` (691 & 772 lines) -> `args.rs`, `dispatch.rs`, `bench.rs`, `commands/{mod,util,info,atx,video,edid,msd,wol,type_text,fixtures,bridge,tests}.rs` (max 318 lines).
  - `apps/cometdesk-gui/src/app.rs` (646 lines) -> `apps/cometdesk-gui/src/app/{mod,events,window,connect,macos,control}.rs` (max 390 lines).
  - `crates/cometdesk-media/src/{flexfec,rtc}.rs` & `crates/cometdesk/src/client.rs` -> `flexfec/{mod,tests}.rs`, `rtc/{mod,audio,tests}.rs`, `client/{mod,session,tests}.rs`.
  - Added `CLAUDE.md`, `docs/ARCHITECTURE.md`, `scripts/check-file-size.sh` (wired into `.github/workflows/ci.yml`), and `README.md` indexes in every module directory.
- **WHY:** Several core files (1,100–10,116 lines) exceeded practical LLM read/edit windows and mixed unrelated concerns.
- **HOW:** Used multiple `impl` blocks across child modules and `pub use` re-exports at module roots to keep all external API and crate paths unchanged.
- **IMPACT:** Largest non-vendor, non-generated `.rs` file in the workspace is now 568 lines (`hid.rs`); CI enforces the 600-line cap via `scripts/check-file-size.sh`.

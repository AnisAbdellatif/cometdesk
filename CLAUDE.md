# cometdesk-rs: guide for AI agents

Native console for GL.iNet GLKVM devices (macOS first). Read `docs/ARCHITECTURE.md` for the
data flow, `PLAN.md` for goals and decisions, `docs/protocol.md` for the device protocol.

## Working rules
- Files stay under 400 lines (hard cap 600, `scripts/check-file-size.sh`, run in CI). Tests live
  in a sibling `tests.rs`. If a file grows past the cap, split it by responsibility.
- Every `.rs` file starts with a `//!` header: what it owns, entry points, what to read to change X.
- Every module directory has a `README.md`: one line per file. Read it, then open only the
  file you need. Do not read whole directories.
- Refactors are mechanical moves: no behaviour change, keep public paths via `pub use`.
- Verify: `cargo fmt --all --check && cargo clippy --workspace --all-targets -- -D warnings && cargo test --workspace`

## Do not read (large, generated or third-party)
`vendor/` (patched str0m, see `vendor/str0m/CometDesk.md`), `target/`, `bridge/target/`, `dist/`,
`graphify-out/`, `crates/cometdesk/src/layout/data/` (@generated by `scripts/gen-layouts.py`).

## Where to change X
| Change | Read |
|---|---|
| Device REST API (ATX, MSD, streamer, EDID, WoL) | `crates/cometdesk/src/api/` |
| Login, session, TLS pinning | `crates/cometdesk/src/{client,tls}.rs` |
| HID wire format, key typing layouts | `crates/cometdesk/src/{hid,layout/}` |
| Video/audio transports (direct, Pion, Janus), decode | `crates/cometdesk-media/` |
| Render pipeline, input mapping, keymap, QoS | `crates/cometdesk-view/` |
| Clipboard / file / notification protocol (Noise) | `crates/cometdesk-clip/` |
| Target-side agent (clipboard, info, update) | `apps/cometdesk-agent/` |
| GUI: window and events | `apps/cometdesk-gui/src/app/` |
| GUI: device list and connect forms | `apps/cometdesk-gui/src/devices/` |
| GUI: session console (toolbar, menus, palette, input) | `apps/cometdesk-gui/src/console/` |
| GUI: clipboard bridge to the agent | `apps/cometdesk-gui/src/clipsync/` |
| GUI: widgets, colours, icons | `apps/cometdesk-gui/src/theme/` |
| CLI | `crates/cometdesk-cli/` |
| KVM-side bridge (RNDIS, Python) | `bridge/`, `docs/clipboard-bridge.md` |

(Directories above are the target layout; until a split lands the path is the file of the same name.)

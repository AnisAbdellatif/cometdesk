# CometDesk redesign: implementation spec

Source of truth: the HTML mockups in `.impeccable/design-ref/` (read the `.html` files: they use inline styles, so every size, colour and gap is explicit) and their renders (`*.png`, 1280×832). Feature inventory: `.impeccable/ui-inventory.md`. Every function in the inventory must stay reachable; the mockups only show some screens, so unshown controls (Session, System info, Media, Clipboard details, Audio output, Display menus, file browser, dialogs, prompts, overlays) must be restyled in the same language.

App: `apps/cometdesk-gui` (egui git rev fc9d66d / 0.37 on wgpu, macOS). Main files: `src/theme.rs` (palette, style, helpers), `src/devices.rs` (connect screen, form, prompts), `src/console.rs` (session UI: toolbar, panel, palette, overlays), `src/media.rs`, `src/browser.rs`.

## Hard constraints
- egui only: no HTML, blur, gradients or shadows beyond what egui draws. Draw icons with `Painter` (lines, circles, polygons): the default font has no arrow/symbol glyphs, and Inter has few either (use drawn chevrons, search glass, pencil, trash, plus, fullscreen corners, check mark).
- Reactive repaint only: no continuous animation, no `request_repaint` loops.
- Dark theme only. Do not add dependencies. Do not remove features. Keep Right-Cmd shortcuts (V, F, S, T, K).
- Keep code simple, no dead code, `cargo clippy -p cometdesk-gui --all-targets` clean, `cargo fmt -p cometdesk-gui`, `cargo test -p cometdesk-gui` passing (19 tests).
- Do not touch files outside `apps/cometdesk-gui/` except the screenshot tools. Do not commit.

## Conventions
- All new reusable widgets go in `theme.rs` (e.g. `chevron`, `icon_button`, `segmented`, `switch`, `kbd`, `dropdown_button`, `card`, `caption`, `modal_frame`), used by devices.rs/console.rs/media.rs/browser.rs.
- Fonts: install in `theme::apply`; keep a `bold` family (Inter SemiBold) for titles and buttons, `mono` for JetBrains Mono. `RichText::strong()` must still look right.
- Verify visually: `.impeccable/tools/shot.sh <name>` launches the debug app against the dev Comet (needs `.env`, already present) and writes `/tmp/shots/<name>.png`. In debug builds `COMETDESK_DEBUG_UI=panel-target|panel-video|panel-settings|palette` opens that view at start (task 3 adds it). Compare with the PNGs in `.impeccable/design-ref/`.

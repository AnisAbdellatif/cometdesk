# console/menus

- `mod.rs` — Submodule declarations for dropdown widgets and drawer menu sections.
- `widgets.rs` — Shared popup menu frame, separator and button item widgets.
- `video_menu.rs` — Video tab in the right-hand drawer: viewer transport/audio and whole-device encoder settings.
- `info_menu.rs` — System info and virtual media collapsible sections in the Target drawer tab.
- `session_menu.rs` — OS session actions card (lock, sleep, log off, restart, shut down) and target notifications.
- `display_menu.rs` — Per-display resolution picker, EDID matching and primary display toggle.
